# 한울연구소 문서 업무 도우미: 최종 설계

확인 기준일: 2026-09-08. 이 문서는 책의 교육용 프로젝트를 설명한다. 실제 조직의 운영 승인서가 아니다.

## 목적과 사용자

Python 개발자가 사전 학습 모델의 입력·출력 계약, 권한 있는 검색, 확인한 도구 실행, 평가와 운영의 경계를 재현한다. 문서·사용자·티켓은 모두 가상이다. 코드가 실행되는 사실과 생성 품질의 채택을 분리한다.

## 구성과 데이터 흐름

- 질의: 로컬 HTTP 토큰 검사 → 단일 가상 주체 → E5 질문 임베딩 → SQLite 권한·시행일 검색 → 토큰 예산 → Qwen 생성 → Answer/인용 검사 → 최신 근거 재확인 → 상태·출처 반환.
- 색인: 정규화한 UTF-8 → 청킹 → 고정 E5 공간 → 전체 스냅샷의 원자적 교체 → 순번·권한·삭제 유지.
- 티켓: 엄격한 인자 → 불변 초안 → 신뢰된 호스트의 확인 → 현재 권한 재검사 → 같은 초안의 단일 등록 → 감사와 조회.
- 매체: 가상 이미지 OCR와 합성 질문 ASR → 중간 결과 검토. 자동 정책 승인·음성 승인으로 연결하지 않음.

HTTP는 localhost 단일 사용자 교육용이며 일반 사용자 인증·인터넷 공개용 서버가 아니다. 별도 비동기 실험은 큐·마감의 원리를 검증하며 실제 모델 처리량을 측정하지 않는다.

## 고정 기준

모델·임베딩·음성·OCR 리비전은 부록 D에 기록했다. 기본 SDK는 openai 3.8.0, httpx2 2.12.0, Pydantic 2.13.5. 로컬은 Transformers 5.16.1/PyTorch 2.14.0 CPU float32 4스레드. MCP SDK 1.30.0, 협상 2025-11-25. 최종 설치 목록은 examples/requirements-final-lock.txt.

## 검증과 결정

106개 자동 테스트는 계약·권한·개정·중복·실행 제어·평가 누락·매체 검사 경계를 확인한다. 실제 E5/Qwen, MCP 프로세스, Tesseract/Whisper, HTTP와 파일 DB 실행을 별도 기록했다.

실제 Qwen RAG의 필수 필드 누락과 의미 실패는 채택 보류다. 실제 Whisper tiny도 가상 질문의 핵심 단어를 잘못 인식했다. 이 결과를 성공으로 바꾸기 위해 출력 계약을 낮추거나 전사를 수선하지 않았다. 검증된 기능 연결과 생성 품질의 미충족을 함께 제시한다.

학습·영상/이미지 생성·원격 MCP·관리형 검색·ANN·동적 LLM 계획은 원리·선택 기준 또는 심화 설계 범위이며 실측을 주장하지 않는다. 무료 로컬 실습의 완성을 위해 외부 API 결제나 계정을 요구하지 않는다.

## 운영 경계와 후속 판단

현재 공개 운영 승인은 보류다. 독립 품질 평가·출력 제약/대체 모델, 다중 사용자 인증, 확인 UI/승인 만료·취소, 실제 추론 동시 부하, 외부 티켓의 결과 불명 복구가 운영 확장의 우선 항목이다. 이는 집필되지 않은 장이 아니라 완성된 원고에서 명시한 적용 범위와 확장 과제다.

프롬프트 복귀는 같은 최신 문서·권한 DB를 유지한 채 프로세스를 재시작해 검증했다. 문서/권한을 과거로 무조건 되돌리지 않는다. DB 스키마 마이그레이션·백업 복원은 별도 운영 설계가 필요하다.
