## 8장 진행

데이터 수집·식별자·시행 구간·텍스트 파싱·청킹·지속 저장·근사 검색 원리·권한·원자적 갱신·삭제 순번·재색인·저장소 선택을 집필했다. SQLite/Python sqlite3/pgvector/Qdrant 공식 문서, HNSW 논문, pypdf 추출 문서를 확인했다. 각 근거는 관련 본문에 링크했다.

실습은 SQLite 지속 저장과 Python 전수 검색을 대표 구현으로 삼았다. 실제 E5 임베딩에 연결한 문서 생명주기 시연과 오류·경쟁 테스트를 수행했다. ANN은 설명·대안 비교 범위이며 실측하지 않았다. PDF/OCR 파싱도 구현했다고 주장하지 않는다.

다음은 9장 RAG 통합이다. 검색 후보를 문맥 구성·구조화 답변·인용 검사와 연결하고, 실제 모델의 근거 부족·권한·잘못된 인용 결과를 검증해야 한다. 전체 원고의 나머지 장·부록·운영 프로젝트·최종 검토는 남아 있다. goal은 active다.


## 9장 진행

RAG의 검색·문맥·생성·인용 책임, 근거 부족·상충 자료·권한 재검사, 단계별 실패와 실제 통합을 집필했다. RAG 원 논문과 ALCE 인용 평가 논문을 확인해 본문에 연결했다. 원 논문의 학습 방법을 재현한 것으로 설명하지 않았다.

실제 E5/SQLite/Qwen 통합에서 세 생성 사례를 두 프롬프트로 비교했다. 둘 다 필수 필드 누락으로 거부됐고 숙박비 오답·상충 자료 선택의 의미 실패도 남았다. v2는 첫 결과를 보고 만든 개발 실험이므로 독립 평가 집합으로 취급하지 않는다. 검증 규칙을 낮추거나 원문을 자동 수선해 통과시킨 기록은 없다.

서비스 경계와 정상 인용 연결은 대역 생성기 포함 통합 테스트로 검증했다. 실제 모델 채택 기준은 미통과다. 전체 목표의 완성 감사에서 이 문제를 다시 확인해야 한다. 모델 교체·제약 생성·독립 평가를 통한 답변 품질 개선이 남아 있다.

다음은 10장 검색 개선이다. 현 실험의 생성 오류를 검색 개선이 해결했다고 주장하지 않으며, 검색 쪽에는 별도의 후보 누락·키워드·하이브리드 비교 자료를 마련한다. 전체 원고 후반부·부록·운영 구성·최종 검토가 남아 있고 goal은 active다.


## 10장 진행

키워드·의미 검색 비교, RRF, 재순위화 원리, 통제 실험, 프레임워크·관리형 검색, 실측 해석을 집필했다. SQLite FTS5, RRF 원 논문, BERT 재순위화 논문, LangChain/LlamaIndex 공식 검색 자료를 확인했다. LangChain 기존 경로가 Deep Agents 검색 안내로 리디렉션돼 실제 열린 URL을 인용했다.

실제 E5/FTS5/RRF 비교에서 숫자 뒤 한국어 조사 때문에 식별자 검색이 실패하는 현상을 확인하고 수정했다. 원본 기록을 보존했다. 수정 후 키워드는 식별자를 찾았지만 RRF의 의미 검색 대비 추가 1위 이득은 없었다. 재순위화·프레임워크·관리형 검색은 대안 설명 범위이며 실측했다고 주장하지 않는다.

다음은 11장 도구 호출·MCP다. 검색 개선의 지속 색인·권한/시행일 연결과 더 어려운 평가 집합도 후속 통합 과제로 남는다. 실제 생성 모델의 품질 문제, 후반부 전체 원고, 부록·배포·최종 검토는 여전히 남아 있다. goal은 active다.


## 11장 진행

도구 요청/실행 분리, 입력 검증·인증 주체·확인·멱등성·감사·결과 표시, MCP 구조·stdio 연결·원격 인증 경계를 집필했다. MCP 2025-11-25 도구·아키텍처·전송·권한 명세와 공식 Python SDK를 확인했다.

SDK 1.30.0을 설치해 실제 서버 프로세스와 연결했다. bare dict 반환에서 structuredContent가 없던 실패를 확인하고 설치 SDK 소스를 검사해 dict[str, Any] 및 structured_output=True로 수정했다. 승인 전 거부, 승인 후 등록, 동일 초안 재실행, 조회, 권한 회수 후 거부와 티켓 한 개를 확인했다.

다음은 12장 워크플로·에이전트다. 현재 MCP 시연은 클라이언트가 정해진 호출을 수행하며 모델의 도구 선택은 검증하지 않았다. 원격 인증·승인 만료/취소·실제 UI 확인도 남아 있다. 9장 모델 품질 문제와 후반 원고·부록·운영 구성·최종 검토를 계속해야 한다. goal은 active다.


## 12장 진행

고정 워크플로·동적 선택·관찰·한도·부분 실패·평가·다중 에이전트 격리·SDK 책임을 집필했다. ReAct 논문, Anthropic 워크플로/에이전트 설계 안내, LangGraph persistence 문서를 확인했다. 직접 실행 루프와 대역 계획기를 대표 구현으로 삼고 실제 LLM 계획·다중 에이전트/SDK 실행과 구별했다.

초안 생성은 확인 대기에서 멈추며 승인/등록은 계획기 행동에 없다. 11장 업무 클래스를 사용한 시연과 반복·예산·시간·스키마·관찰 변조 테스트를 완료했다. 강제 취소·영속 체크포인트·실제 금액 예약은 구현하지 않았음을 명시했다.

다음은 13장 파인튜닝 선택이다. 9장 실제 모델의 행동 불일치 사례를 활용하되, 실패 몇 개만으로 학습이 필요하다고 단정하지 않고 데이터/평가/대안을 비교한다. 이후 14–18장·부록·전체 통합·실제 모델 품질 개선·최종 검토가 남아 있다. goal은 active다.

## 13장 진행

파인튜닝 도입 판단, 지식/행동/서버 결함의 구분, 프롬프트·검색·제약 생성·모델 교체 비교, 분할 누수, SFT 손실과 응답 마스크, LoRA/QLoRA 원리, 회귀·비용 판단을 집필했다. LoRA/QLoRA 원 논문과 TRL 공식 SFT 문서를 확인해 관련 본문에 연결했다.

교육용 표본 9행과 데이터 검사기를 추가했다. 5개 계열을 train/dev/test에 분리하고 실제 인용·필수 필드·동일 입력 누수를 검사한다. 근접 중복과 정답 의미의 검증은 제공하지 않으며 이를 테스트와 본문에서 명시했다. 전체 97개 테스트, 사이트 빌드와 13장 링크 검증을 통과했다.

학습은 실행하지 않았다. 현재 도입 판단은 보류이며 학습 전후 개선 수치는 없다. 다음 집필은 14장 멀티모달이다. 9장 실제 생성 품질 개선·독립 평가, 후반 원고·부록·운영 통합·최종 퇴고는 남아 있다. 전체 목표는 미완료다. 도구에서 확인한 goal 상태는 paused이며 이 턴은 사용자의 계속 요청에 따른 집필 진행이다.

## 최종 집필·검토 완료

2026-09-08 사용자의 “끝까지 모든 장을 써” 요청에 따라 14–18장과 부록 A–E를 모두 집필했다. 이전 기록의 “다음 집필” 및 “후반 원고 미완료”는 당시 상태이며 현재는 18장·부록 5편 모두 본문이 있다.

14장: 실제 Tesseract 한국어 OCR, Yuna 합성 질문, Whisper tiny 전사를 실행했다. 문서 OCR는 표본 원문과 같았고 전사는 “주유기 한 돈인 얼마인가요?”로 틀렸다. 수선하지 않고 중간 확인 경계를 설명했다. 15장: 다른 조직 비밀 표식의 계수 전 차단·가짜 인용·승인 사칭 경계를 추가했다. 16장: 실행 ID 누락·중복 거부, 생성 완료/계약/상태/의미 채점의 분리를 구현했다. 17–18장: 실제 로컬 가중치 HTTP와 티켓 CLI, 별도 합성 큐·마감·복귀를 실행하고 설명했다.

모든 주요 영역에 원리·실패·선택 기준을 연결했고 근거 문서를 확인했다. 실행하지 않은 학습·영상/이미지 생성·원격 인증·외부 운영을 검증한 것으로 표시하지 않았다. 실제 Qwen의 생성 품질 문제는 해결됐다고 주장하지 않고 운영 채택 보류와 다음 실험의 조건으로 최종 설계에 정리했다. 자유 생성 모델의 품질 개선은 원고의 빈칸이 아니라 독자가 적용 시 통과해야 하는 조건이다.
