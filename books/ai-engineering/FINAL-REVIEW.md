# 최종 원고 검토

기준일: 2026-09-08. 구성: 6부 18장, 부록 A–E 5편. 웹 본문 23개.

## 범위와 서술

PLAN v2의 모든 장·부록에 본문을 작성했다. 역할·모델·API·문맥·프롬프트·로컬 실행·임베딩·저장소·RAG·검색 개선·도구/MCP·워크플로·파인튜닝·멀티모달·보안·평가·운영·개발 도구를 다룬다. roadmap 대응표와 재구성 이유는 PLAN 및 ROADMAP-VERIFICATION에 보존했다.

초기 예상 24만–32만 자는 강제 분량이 아니었다. 완성 원고는 약 17만 9천 자(공백·코드·frontmatter 포함)다. 중복되는 API/권한/평가 설명을 후반에서 앞 장에 연결하고 심화 미실행 영역을 명확히 구분했다. 글자 수를 맞추기 위한 반복은 추가하지 않았다.

주요 기술의 문제·원리·구현·실패·측정·대안을 확인했다. 전문적인 한국어 평서체와 코드 상태 표기를 유지했다. 질문 없음과 조회 실패, 생성 완료와 계약 통과, 인용 존재와 의미 지지, 모델 행동과 서버 권한을 구분했다. 빈 장·TODO·본문 작성 예정 표시는 없다.

## 실행과 사실 검토

공식 문서·원 논문을 관련 본문에 연결했다. 후반 자료는 Tesseract/Whisper/Transformers, OWASP, 정보 검색 교재/ALCE/모델 평가자 논문, Python/OTel/SRE, GitHub 개발 에이전트 문서를 확인했다. 일부 이전 문서 경로가 오류/리디렉션되어 실제 열린 공식 경로를 사용했다.

자동 테스트 106개, 실제 로컬 OCR/ASR, HTTP/CLI/파일 DB와 프롬프트 재시작, 합성 큐 장애/복귀를 실행했다. 실제 모델의 품질 실패를 원고에 포함했고 평가 결과를 조작하지 않았다. 숫자는 실측 또는 교육용 가정으로 구분했다. 유료 API·학습·영상/이미지 생성·외부 공개 운영을 실행했다고 쓰지 않았다.

## 사용성과 전달

부록에 코드·실험 기록 다운로드와 실행 순서를 제공한다. 모델 캐시·비밀·가상 환경·합성 매체는 다운로드 묶음에서 제외한다. 환경·모델·데이터 리비전과 의존성 목록을 제공한다.

정적 검증은 23개 본문과 표지, 내부 링크/앵커/canonical/양쪽 사이트맵을 비교한다. Chromium으로 1440px/390px에서 46개 페이지-뷰포트 조합의 제목·현재 장·가로 넘침을 확인하고 모바일 목차·다음 장 이동·한국어 검색 세 질의를 실행했다. 화면 캡처는 직접 확인했다. 최종 메타데이터에서 연재 중 표시를 해제한다.

## 명시적 한계

책 원고의 완성과 예제 모델의 운영 채택은 다르다. Qwen RAG와 Whisper tiny의 품질 문제는 14·16·18장과 FINAL-DESIGN에 채택 보류로 정리했다. 실제 사용자 연구, 운영 다중 인증, GPU/클라우드 부하, 법률 준수 인증은 이 교육용 책의 검증 범위가 아니다. 역사적 EDITORIAL의 다음 장·미완료 문장은 해당 시점의 진행 기록이며 최신 상태는 이 문서와 마지막 기록을 따른다.
